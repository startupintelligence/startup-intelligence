# Startup Intelligence

An independent digital project exploring startup ecosystems, emerging technologies, business models and the ideas behind new ventures. This is not a registered company.

## Website

Published with GitHub Pages: https://startupintelligence.github.io/startup-intelligence/

## Page structure

- `index.html` — Home
- `about/index.html` — About (`/about/`)
- `explore/index.html` — Explore (`/explore/`)
- `research/index.html` — Research (`/research/`)
- `contact/index.html` — Contact (`/contact/`)
- `privacy/index.html` — Privacy Policy (`/privacy/`)
- `terms/index.html` — Terms and Conditions (`/terms/`)
- `assets/icons/` — favicon and app icon assets

Pages use folder-based `index.html` files so visitors can use clean URLs without `.html` filenames. Internal links are relative to the GitHub Pages project path.

## Maintenance notes

Review the Privacy Policy and Terms whenever actual site practices change. Do not add analytics, forms, accounts, payment processing or other data collection without updating the relevant disclosures and security controls.
