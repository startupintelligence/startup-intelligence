## Important current status

This repository is deployed as a static GitHub Pages site. The collection cards are illustrative design concepts, not live demos or completed client work. Pricing is quote-based until actual prices are configured. The custom inquiry form, accounts, customer dashboard, admin CMS, database, secure uploads, notifications, and checkout are not implemented in this static phase. Login pages remain non-functional previews and must not be used to collect real credentials.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the staged implementation plan and security boundaries. See [PRELAUNCH-CHECKLIST.md](PRELAUNCH-CHECKLIST.md) for launch checks.

The project is not a registered company. Do not publish unverified contact details, prices, customer logos, testimonials, metrics, or legal claims.
